# Databricks-Retail-Sales-Analytics-

## Project Overview
This project analyzes retail sales data using Databricks SQL and presents business insights through data analysis and visualizations.

## Project Objectives
- Analyze overall sales performance.
- Identify the top 5 products by sales revenue.
- Analyze sales performance across regions.
- Explore monthly sales trends.
- Understand product category contribution to total sales.

## Tools and Technologies
- Databricks SQL
- SQL
- Unity Catalog
- Databricks Genie
- AI/BI Dashboards

## SQL Analysis
This repository contains SQL queries for the following tasks:

1. Overall Sales Performance
2. Top 5 Products by Sales Revenue
3. Regional Sales Performance
4. Monthly Sales Trend
5. Product Category Contribution
